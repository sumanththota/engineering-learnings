# Agents write only when asked; no proactive lesson-detection for now

We considered letting an agent notice a reusable lesson mid-task and proactively draft/propose it for this repo (draft-and-ask). We're starting simpler: Sumanth initiates every addition explicitly; an agent doesn't need to watch for or judge "is this worth capturing" on its own. This keeps the repo's growth fully deliberate while the write-back pattern is still new, and can be revisited once the manual pattern feels like it's missing things.
