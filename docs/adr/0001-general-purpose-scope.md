# General-purpose scope, not AI-agent-specific

All 20 seed lessons came from one AI-agent-orchestrated migration, which risked biasing the repo's taxonomy toward agent-workflow concerns only. We decided this repo captures engineering learnings from *any* project, not just AI-agent-driven ones — matching the original consolidation plan's wording ("learnings from every project"). `project` and `tags` should stay domain-agnostic; don't assume future entries involve agents or LLMs.
